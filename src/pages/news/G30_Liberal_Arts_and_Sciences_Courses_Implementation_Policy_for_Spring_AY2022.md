In the spring semester of AY2022, Liberal Arts and Sciences Courses will be conducted using either of the following methods in order to avoid the “Three Cs” and to keep the distance between students.

A.  Face-to-face classes  
Classes conducted face-to-face in lecture rooms, etc.

B.  Remote classes using on-demand methods 	
Classes conducted remotely using a PC with video and audio files, regardless of the timetable.  

C. Remote classes using simultaneous interactive methods	 
Remote classes conducted from a PC using Microsoft Teams, Zoom, etc., according to the timetable.

From [this page](https://officetest.ilas.nagoya-u.ac.jp/files/kyoki/G30/01_Spring2022_G30-Timetable-Class_Implementation_Method-HP.pdf) , there is a timetable with information on the methods of conducting classes, therefore, please refer to it when taking courses. (<font color="red">The revised parts are written in red. Updated on June 15.</font> )

Some courses may be conducted using several different methods.  
Ex: 
    ・A in principle, but B in some classes  
    ・C in principle, but A in some classes  
    ・Combination of B and C  

**Access Point**  
In principle, remote classes B and C should be taken from home.  
However, if there is a problem with the network environment at home, or there is a remote class of C (simultaneous interactive type) just before the face-to-face class of A, etc., it is possible to take the class at an access point on campus.  

**NUCT**  
Information on course implementation methods, distribution of course materials, and other notices will be shown in the notices section of each class page displayed on [NUCT](https://ct.nagoya-u.ac.jp/portal) *.
